# BU1LD 64 — Overnight Build Queue (2026-09-28)

This is the canonical incubation queue for the 64-project overnight cohort.

## Incubation gate

A project is **ready for a standalone BU1LD repository** only when:
- a deterministic end-to-end v0 runs;
- tests pass;
- the first benchmark is defined and at least one baseline runs;
- literature/competitor review is complete enough to make a novelty decision;
- the target user and product wedge are explicit;
- empirical claims are backed by executed artifacts;
- blockers and negative results are recorded instead of hidden.

## Execution rules

1. Do not fabricate benchmark values, citations, or SOTA claims.
2. Prefer a small runnable v0 over a large non-runnable scaffold.
3. If a project is duplicate/non-novel, merge or retire it rather than forcing a new repo.
4. Use ResearchPilot/LabOS integrations only after the core project passes its gate.
5. Each overnight pass should take the next incomplete batch of eight.
